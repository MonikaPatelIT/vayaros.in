# Vayaros — Banana Chips SPA

React/Vite single-page product website. Designed for Vercel.

## Local setup
```bash
npm install
npm run dev
npm run build
```

## Deployment
Import this GitHub repository into Vercel as a **Vite** project; use `npm run build` and output directory `dist`. The project requires no environment variables.

## Before launch
- Confirm official Instagram profile and stockist/order availability.
- Replace the illustration with approved high-quality product images.
- Add the actual founder footage with permission (see original media bundle retained outside GitHub).
- Confirm customer service and business contact details from the final printed pack.

Content and design are a first draft, not a final regulatory packaging review.
